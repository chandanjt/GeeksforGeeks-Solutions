# GeeksforGeeks Solutions

This repository contains a public collection of verified GeeksforGeeks problem solutions saved from my practice history. It is intended as a personal reference set for DSA review, interview preparation, and algorithmic problem-solving practice.

## Scope

The public repository includes the verified export set from the solved problem list and keeps the original source code intact. The exported solutions are stored in a clean public layout and are intentionally separated from private browser state and local export artifacts.

## Included Solutions

- 381 verified problem entries in the public set
- 382 source files preserved in the public layout, including one duplicate-language variant with the same slug
- Languages represented: C++, Java, JavaScript

solutions/

## Repository Notes

- Local-only browser state and authenticated Playwright data are intentionally excluded from Git.
- Private export snapshots, diagnostics, and temporary artifacts are kept out of the public repository.
- The repository is focused on the exported public source code rather than private platform data or local automation state.

## Quick Start

Browse the repository files directly, open any solution, and use the source as a personal reference. The goal is to preserve original solutions while keeping the repo clean and publication-safe.
